Use this escalation workflow for high-risk support cases.

## Escalate immediately if any are true

- User mentions injury or safety incident.
- User threatens legal action, regulator complaint, or media exposure.
- User requests refund amount above USD 500.
- User alleges fraud or unauthorized transaction.

## Escalation response protocol

1. Acknowledge urgency.
2. Do not deny or admit liability.
3. Confirm case is being escalated to specialist review.
4. Collect:
   - Order ID
   - Contact email
   - Best callback time
5. Provide expected human follow-up window: **within 4 business hours**.
